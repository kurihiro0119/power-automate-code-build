# インポート手順

ビルドすると `dist/` に、そのソリューション専用の手順書 (`*_IMPORT.md`) も出ます。ここは共通の説明です。

## A. ソリューションとしてインポート (基本)

必要なもの: **Dataverse のある環境** と、環境作成者以上のロール。

1. https://make.powerautomate.com を開き、右上でインポート先の環境を選ぶ
2. 左メニュー「ソリューション」→「ソリューションをインポート」→ `dist/<名前>_<バージョン>.zip` を選ぶ →「次へ」
3. 「接続」の画面が出たら、コネクタごとに接続を選ぶ。無ければ「新しい接続」でサインインし、戻って「最新の情報に更新」
4. 「インポート」。1〜3 分で完了通知が出る
5. ソリューションを開き、各フローがオンになっていることを確認してテスト実行する

サインインはコネクタごとに 1 回です (ソリューション内の全フローが同じ接続参照を共有します)。

### 更新するとき

ソースを直して再ビルドし、同じ手順でもう一度インポートすると、既存のフローが上書き更新されます。
接続は前回のものが引き継がれます。区別のためにバージョンを上げるなら `python3 -m pabuild bump <名前>`。

注意: インポート後にデザイナーで直した内容は、次のインポートで上書きされます。
デザイナーで直したものを残したいときは、エクスポートして `python3 -m pabuild import <zip> --force` でソースに戻します。

### 環境に Dataverse があるか

Power Platform 管理センター (https://admin.powerplatform.microsoft.com) →「環境」→ 対象の環境 →「Dataverse」の欄で確認できます。
無ければ「データベースの追加」で作るか、下の B を使います。

## B. レガシー パッケージとしてインポート (Dataverse が無い環境)

```bash
python3 -m pabuild build <名前> --legacy
```

`dist/legacy/<ソリューション>_<フロー>_legacy.zip` が 1 フローにつき 1 つできます。

1. 「マイ フロー」→「インポート」→「パッケージのインポート (レガシー)」→ zip を選ぶ
2. フローの行の「アクション」を開き「新規作成」を選ぶ
3. 接続の行はそれぞれ「インポート時に選択する」を開き、既存の接続を選ぶ (無ければ先に「接続」画面で作る)
4. 「インポート」→ 完了後、フローを開いて保存し、オンにする

レガシー形式には公開された仕様が無く、このツールの出力は
実環境のエクスポート 1 件の構造に合わせたものです。**うまく入らないフローがあれば A を優先してください。**
このとき各フローは別々に取り込まれるため、接続もフローごとに選びます。
